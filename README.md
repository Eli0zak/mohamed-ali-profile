# Mohamed Ali Profile

Mohamed Ali's public professional profile and portfolio. The public site is available at `/`.

## Setup

Use Node.js and pnpm, then run `pnpm install` and `pnpm dev`.

Optional platform configuration includes OAuth/session values and storage values. Candidate intake remains at `/career-gateway`; configure this repository with the same database, CV storage, and Google Sheets settings as the Careers repository so the Careers dashboard can manage incoming applications. Set `VITE_CAREERS_DASHBOARD_URL` to show the dashboard link to administrators.

## Commands

- `pnpm dev` — start the development server
- `pnpm test` — run tests
- `pnpm check` — run TypeScript checks
- `pnpm build` — build for production
